# Copper Equilibrium Price — موقع السعر المتعادل للنحاس

هذه الحزمة هي النسخة التشغيلية الأولى للموقع. تعرض:

- **سعر LME Cash** ومخزون LME وLME 3M يوميًا.
- **Structural P\*** الحالي: **10,469 دولار/طن** (حوالي **4.75 دولار/رطل**) مع وسم **PROVISIONAL**.
- الفارق بين سعر السوق وP*.
- نطاق السيناريوهات: Optimistic / Base / Stress.
- حالة النموذج والـBacktest ومقدار اكتمال التاريخ الشهري.
- سجل تاريخي يومي يتراكم تلقائيًا.

## لماذا P* ما زال PROVISIONAL؟

الاختبار السنوي تحسن داخل العينة إلى R²≈73.5% وMAPE≈7.4% بعد إضافة Mine Utilization، لكن الـWalk‑Forward السنوي فشل بسبب قصر العينة. تم نقل المعايرة إلى مستوى شهري، والقاعدة الحالية تشترط **36 شهرًا متصلًا على الأقل** من أساسيات ICSG قبل تحويل الحالة إلى VALID. المتاح الموثق في النموذج حاليًا **11 شهرًا**.

الموقع **لا يختلق بيانات مفقودة**. إذا لم يكتمل Feed حرج تبقى الحالة `PROVISIONAL/STALE`.
